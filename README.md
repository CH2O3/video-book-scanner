# Video Book Scanner

**本をパラパラめくる様子をスマホで撮った動画から、文字で検索できるPDFを作るWindows用のツールです。**

- 動画の中から、ページが止まっている場面を自動で見つけて切り出します
- 見開きを左右のページに分け、傾きや紙の曲がり、影を補正します
- 日本語の文字認識（OCR）をかけて、PDFの中を文字で検索・コピーできるようにします
- 指が写り込んだページや、撮り損ねたページは「要確認」として知らせ、画面で直せます

1冊ずつスキャナーにかける代わりに、スマホで撮影するだけで済ませるためのものです。すべての処理はあなたのパソコンの中で行われ、動画や本の中身がインターネットに送られることはありません。

> いまは試作段階です。横書きの日本語の本で試しています。縦書きの本の文字認識には対応していません。

## 1. はじめに必ず読んでください（著作権とプライバシー）

### 著作権について

- このツールは、**自分で持っている本を、自分で使うためにデジタル化する**ことを想定しています。
- 日本の著作権法では、個人的に使う目的での複製（いわゆる「自炊」）は認められている範囲がありますが、**作ったPDFを他人に渡したり、インターネットに公開・共有したりすることは、著作権の侵害になる可能性が高い**です。
- 図書館や友人から借りた本、他人の本を撮影する場合や、業者に頼む場合などは、扱いが変わることがあります。不安なときは、文化庁などの公式情報を確認してください。
- このツールの作者は、作られたPDFの使い方について責任を負いません。

### プライバシーについて

- 処理はすべてパソコンの中で行われます。動画・ページ画像・PDFが外部に送られることはありません。
- 画面はブラウザで開きますが、これは**自分のパソコンの中だけ**（`127.0.0.1`）で動いている画面です。他のパソコンからは見えません。起動のたびに合言葉（トークン）が変わり、それを知らない要求は受け付けません。
- インターネットに接続するのは、インストール（セットアップ）のときだけです。
- ただし、確認作業をAIエージェントに頼む場合（[7章](#7-aiに確認選別を手伝ってもらう)）は、ページ画像がAIの提供元に送られます。
- 撮影した動画には、手や部屋の様子、本の内容が写っています。作ったフォルダ（動画のコピーが入っています）を人に渡すときは注意してください。

## 2. 用意するもの

| もの | 説明 |
|---|---|
| Windows 10 または 11 のパソコン | メモリ8GB以上を推奨（16GB以上だと安心）。空き容量は、動画の大きさの1.5倍＋2GBくらい（例：12分の4K動画 2.7GB で、作業フォルダは約4GB） |
| スマートフォン | 4Kか1080pで動画が撮れるもの。iPhoneの標準カメラで動作を確認しています |
| スマホスタンド | 手で持つより、真上から固定するほうがきれいに撮れます |
| 明るい部屋 | 影や反射が少ないほど、文字の読み取りがよくなります |

## 3. インストール（最初の1回だけ）

### 手順1：Pythonを入れる

このツールは「Python」というプログラムの上で動きます。

1. [python.org のダウンロードページ](https://www.python.org/downloads/windows/) を開きます。
2. 「**Download Python 3.12.x**」（3.11以上なら可）をクリックして、インストーラーを保存します。
3. 保存したファイルをダブルクリックし、「**Install Now**」を押します。
   - 画面下の「Add python.exe to PATH」にチェックを入れても入れなくても動きます。
   - Microsoft Store 版のPythonではなく、python.org 版を使ってください。

### 手順2：このツールをダウンロードする

1. このページ（GitHub）の上のほうにある緑色の「**Code**」ボタンを押し、「**Download ZIP**」を選びます。
2. ダウンロードしたZIPファイルを右クリック →「**すべて展開**」で、好きな場所（例：ドキュメント）に展開します。
   - フォルダ名に日本語や空白が入っていても動きます。

### 手順3：セットアップを実行する

1. 展開したフォルダの中の **`setup.bat`** をダブルクリックします。
   - 「WindowsによってPCが保護されました」と出たら、「**詳細情報**」→「**実行**」を押してください（インターネットから取ってきたファイルに出る標準の警告です）。
2. 黒い画面が開き、次の3つを自動で行います（10分ほどかかります）。
   - Pythonの部品の準備
   - 文字認識ソフト「**Tesseract OCR**」のインストール（「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」）
   - 日本語の文字認識データのダウンロード
3. 「準備できました」と出たら、何かキーを押して閉じます。

> うまくいかないときは、[8. 困ったとき](#8-困ったとき) を見てください。

## 4. 撮影のしかた

きれいに撮れるほど、あとで直す手間が減ります。

1. **スマホを本の真上に固定**します。見開き全体が画面に入り、紙の周りに少し机が見えるくらいがちょうどよいです。
2. 1枚めくったら、**手を紙から離して1〜2秒止めます**。この「止まっている時間」をツールが見つけて、ページとして切り出します。
3. 押さえる指は、**文字のない余白**に置きます。文字に指がかかると、その部分は読めません（ツールは隠れた文字を推測で埋めることはしません）。
4. 背景は、**紙と違う色の無地**（黒っぽい布や机）がおすすめです。白いシーツの上などは、紙との区別がつきにくくなります。
5. 照明は明るく均一に。光沢のある紙は、照明が反射して写らない角度にします。
6. iPhoneの「HDRビデオ」はオンのままで大丈夫です。スマホを縦に持って本が横向きに写っても、向きは自動で直します。

**例：** 300ページの本なら、見開き150回なので、1回3〜4秒として10分前後の動画になります。

## 5. 使い方

### 起動する

フォルダの中の **`VideoBookScanner.bat`** をダブルクリックします。

- ブラウザ（Edge や Chrome）が自動で開き、ツールの画面が出ます。
- 一緒に開く**黒い画面は、使い終わるまで閉じないでください**（閉じるとツールが止まります）。
- 動画ファイルを `VideoBookScanner.bat` の上にドラッグ＆ドロップしても始められます（動画と同じ場所に `動画名_scan` フォルダができます）。

画面は上のタブで切り替える3つだけです。

### ① 動画を入れる

1. 撮影した動画を、点線の枠に**ドラッグ＆ドロップ**します（またはクリックして選びます）。
   - スマホからパソコンへ動画を移す方法は、お使いのスマホの説明に従ってください（USBケーブル、iCloud、Googleフォトなど）。
   - 大きな動画は、下の欄に**ファイルの場所を貼り付ける**ほうが速く取り込めます（ファイルを右クリック →「パスのコピー」→ 欄に貼り付けて Enter）。
   - 何本かに分けて撮った動画は、全部入れれば入れた順につなげます（順番はあとから変えられます）。
2. **書名**を入れます（PDFのファイル名になります）。
3. **保存先**を確認します。最初は「ドキュメント\VideoBookScanner\書名」になっています。
4. **ページの順番**を選びます。横書きの本は「左→右」、縦書きの本は「右→左」です。
5. 「**処理を開始**」を押します。

「詳細な設定」は、普段は開かなくて大丈夫です。

### ② 処理状況

処理の進み具合が出ます。パソコンにもよりますが、12分の4K動画（約150見開き）で30分弱かかりました。

- 「**中断**」でいつでも止められます。止めても、そこまでの結果は保存されています。
- 「**再開**」で続きから進みます。ブラウザやパソコンを閉じたあとでも、もう一度起動して「前に作った本を開く」から再開できます。
- 途中で止まったときは、理由と「次にできること」のボタンが出ます。

### ③ 確認してPDFにする

処理が終わると、この画面に移ります。

1. 左の一覧に、**確認が必要なページ**が並びます（「要確認」タブ）。クリックすると右に大きく出ます。キーボードの ← → でも移動できます。
2. それぞれのページで、問題を直すか「**問題なし（確認済みにする）**」を押します。直し方は次の章にあります。
3. 直したら、上の「**変更を反映**」を押します。変えたページだけを作り直します。
4. 最後に「**全ページ**」タブで、並び順やページの抜けがないかをざっと見ます。
5. 「**PDFを出力**」を押します。できあがると「PDFを開く」「フォルダを開く」ボタンが出ます。

PDFは、保存先の中の `output` フォルダにできます。

## 6. 「要確認」の意味と直し方

| 表示 | 意味 | 直し方 |
|---|---|---|
| 本文の範囲に手が重なっている疑い | 指や手が文字にかかっているかもしれない | 下の「この見開きの候補」から指が入っていない写真を選び「この候補を使う」。全部だめなら「動画で前後のコマを探す」で、動画を1コマずつ動かして探す |
| 紙面の欠け／端で文字切れの疑い | ページの端が画面からはみ出している、または切り抜きがずれている | 「元の映像」で確認。切り抜きがずれているなら「分割線・切り抜きを直す」で紙の範囲を囲み直す。本当にはみ出しているなら撮り直すか、写真を追加する |
| 綴じ目の位置が不確か | 左右のページの境目がはっきりしない | 「元の映像」で赤い線が綴じ目にあればそのままでよい。ずれていれば「分割線・切り抜きを直す」 |
| 静止が短い | ページを止めた時間が短く、自動では使わなかった | 「未採用の区間」タブで中身を見て、必要なら「この区間を採用する」 |
| 重複の疑い | 同じページを2回撮ったかもしれない | 同じページなら、片方の「見開きごと除外」 |
| OCRの信頼度が低い／文字が認識されない | 文字の読み取りがうまくいかなかった。白紙や図だけのページでもこうなる | 中身が白紙・図なら「問題なし」。文字が多いのに読めていないなら、別の候補を試す |
| ぼけ／露出不足／白飛び | 写真がぶれている、暗すぎる、明るすぎる | 別の候補を選ぶ |
| 紙面の向きを判定できない | 本が横倒しで写っているかを判断できなかった | ページが横倒し・逆さまなら、「動画を入れる」画面の「ページの向きを回す」 |

**確認のコツ**

- 画面の「**補正後／補正前／元の映像**」を切り替えると、どこで問題が起きたかがわかります。
- **ページ番号**を見ると、抜けや重複に気づけます。「全ページ」タブで、ページ番号が順番に続いているかを確かめるのがいちばん確実です。
- 湾曲補正や余白の白塗りが悪さをしているときは、見開きごとに「しない」に切り替えられます。
- 足りないページは、スマホで写真を撮って「写真を追加する」で入れられます。

## 7. AIに確認（選別）を手伝ってもらう

要確認が多いときは、AIエージェントに確認作業を任せることもできます。たとえば約280ページの本で、AIにページ番号を1枚ずつ読ませて、抜けていたページ（2見開き）と余分な見開き（18個）を見つけ、候補の差し替えまで済ませた例があります。

### 頼める環境の条件

ブラウザで質問するだけのチャット（文章や画像を貼って答えてもらう使い方）では、この作業はできません。次の**すべて**を満たすAIエージェントが必要です。

| 条件 | なぜ必要か |
|---|---|
| **あなたのパソコン上で動き、ファイルを読める** | 保存先フォルダの中のページ画像や `project.json` を読むため |
| **画像を見て内容を判断できる** | ページ番号を読んだり、指が文字にかかっているかを見たりするため |
| **コマンドを実行するか、パソコン内のブラウザを操作できる** | このツールの画面（`127.0.0.1`）を操作して、候補の差し替えや除外を行うため |
| **長い作業を続けられる** | 数百ページを1枚ずつ確かめるので、数十分かかります |

例：Claude Code（デスクトップアプリやコマンドライン版）のように、パソコンのファイル操作・コマンド実行・画像の確認ができるAIエージェント。

**頼む前に知っておいてほしいこと**

- **ページ画像がAIの提供元に送られます。** 「処理はすべてパソコンの中」というこのツールの前提から外れます。本の内容をAIサービスに送ってよいか、AIサービスの利用規約や、送ったデータが学習に使われない設定になっているかを、事前に確認してください。
- AIの利用料金（または利用プランの使用量）がかかります。ページ数が多いほど多くなります。
- AIは間違えることがあります。最後に「全ページ」タブで、ページ番号が続いているかを自分の目でも確認してください。

### 頼み方

1. `VideoBookScanner.bat` で画面を開き、処理を最後（文字認識まで）終わらせておきます。
2. 黒い画面に出ている `http://127.0.0.1:…/#t=…` のアドレスをコピーします（`#t=` の後ろは、起動のたびに変わる合言葉です。AI以外には教えないでください）。
3. 保存先フォルダ（例：`C:\Users\あなた\Documents\VideoBookScanner\書名`）と、このツールを展開したフォルダの場所を確認します。
4. 次のプロンプトの `【 】` を書き換えて、AIエージェントに渡します。

```text
Video Book Scanner で本をPDFにしている。確認画面での選別を代わりにやってほしい。

- 画面のアドレス：【http://127.0.0.1:12345/#t=xxxxxxxx】
- 保存先フォルダ：【C:\Users\あなた\Documents\VideoBookScanner\書名】
- 本の情報：【横書き・左から右へ読む。本文は1〜278ページ、その前に目次などがある】
- ツールのフォルダ：【C:\Users\あなた\Documents\video-book-scanner】
- 操作方法は、ツールのフォルダにある docs\DEVELOPMENT.md の「画面のAPI」を読むこと。
  画面を操作するか、そのAPIを使う。project.json を直接書き換えてはいけない。

やってほしいこと（この順で）：
1. 全ページのページ番号（ノンブル）を画像で読み、表にする。
   抜けているページ、同じページの重複、めくり途中の崩れた見開きを見つける。
2. 抜けているページは「未採用の区間」の中から探して採用する。
   重複やめくり途中の見開きは除外する。
3. 要確認のページを1枚ずつ見る。
   - 指や手が文字にかかっていたら、同じ見開きの別の候補と比べ、文字が一番見えるものに替える。
     候補が全部だめなら、動画の前後のコマ（1コマずつ）から探す。
   - 切り抜きがずれていて文字が欠けていたら、分割線・切り抜きを直す。
   - 余白の指や端の黒い線だけで、文字が全部読めるものは「確認済み」にする。
4. 変えたら「変更を反映」を実行し、作り直したページをもう一度見て確かめる。

守ってほしいこと：
- 隠れて読めない文字を推測で補わない。どの候補でも読めない箇所は、そのまま報告する。
- 本文の文章を書き写したり、外部に送ったりしない（ページ番号と短い見出しの確認だけでよい）。
- 設定の変更、ファイルの削除はしない。
- PDFの出力は【する／しない】。

最後に、次をまとめて報告してほしい：
直したページと理由、除外した見開きと理由、自分では直せなかったページ、
ページ番号が最初から最後まで続いているかどうか。
```

**ポイント**

- 「本の情報」にページの範囲を書いておくと、抜けや重複を見つけやすくなります。
- PDFの出力までAIに任せるか、自分で最後に確認してから押すかを選べます。慣れるまでは「しない」にして、報告を読んでから自分で出力するのがおすすめです。
- 作業中は、画面の黒いウィンドウを閉じないでください。

## 8. 困ったとき

**`setup.bat` で「Pythonが見つかりません」と出る**
→ 手順1のPythonが入っていません。python.org 版を入れてから、もう一度 `setup.bat` を実行してください。

**`setup.bat` で Tesseract のインストールに失敗する**
→ `winget`（Windowsの標準のアプリ導入機能）が使えない環境です。[UB Mannheim の Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) からインストーラーを入れて、もう一度 `setup.bat` を実行してください。

**ブラウザが開かない**
→ 黒い画面に `http://127.0.0.1:…` で始まるアドレスが出ています。それをブラウザに貼り付けて開いてください。

**処理がとても遅い**
→ 4K動画は時間がかかります。撮影を1080pにすると速くなります。処理中はパソコンをスリープさせないでください（スリープしても、再開すれば続きから進みます）。

**「空き容量が不足しています」と出る**
→ 保存先のドライブを空けてから「再開」を押してください。

**PDFの文字が一部まちがっている**
→ 文字認識は完璧ではありません。特に数字の「0」と英字の「O」、小さな文字、図の中の文字は誤りやすいです。大事な部分は元の画像で確認してください。

## 9. できないこと・苦手なこと

- **縦書きの本の文字認識**には対応していません（ページの順番は右→左にできます）。
- 綴じ目の近くで紙が大きく曲がっていると、文字が詰まって読みにくくなります。本を十分に開いて撮ってください。
- 光沢紙の照明の反射、強い色の照明の下での撮影は苦手です。
- 指や手で隠れた文字は、復元できません（推測で埋めることもしません）。
- 撮っていないページがないことまでは保証できません。ページ番号で確認してください。
